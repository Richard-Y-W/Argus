# Adversarial review: Hwang current-collaborator probe

**Verdict:** NOT SUPPORTED for the broad collaborator proxy; INCONCLUSIVE for costly commitments  
**Promotion:** prohibited

## Exact result

In Hwang's 24-event published sample, a collaborator appears in the current ClinicalTrials.gov record for 25.0% of positive events and 37.5% of negative events. The odds ratio for a positive outcome is 0.556; Fisher's two-sided exact p-value is 0.647.

## Blocking findings

1. **Timing:** all collaborator fields were retrieved from the 2026-08-21 record, after the 2011–2013 outcomes.
2. **Construct validity:** collaborator listings combine owners, commercial partners, public bodies, and trial-service vendors. Presence is not equivalent to costly external commitment.
3. **Sample:** seven large firms dominate; all eight negative observations are Phase III; sponsor and trial dependence is material.
4. **Power:** only seven events have a current collaborator. The prespecified minimum of ten qualifying commitments is not met even under this broader proxy.
5. **Tradability:** no point-in-time signal and no price, cost, liquidity, or execution data exist.

## Minimum next verification

Assemble a post-2015 small-biotech event universe from SEC-filed result announcements, recover the last public trial version before each event, and code asset-specific commitments from filings and exhibits using exact acceptance timestamps. Outcomes must stay hidden until coding is frozen. If fewer than ten qualifying commitments appear in the first 30 events, stop or expand the universe before any return analysis.
