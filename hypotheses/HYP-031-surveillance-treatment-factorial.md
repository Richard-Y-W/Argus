# HYP-031 — Surveillance-treatment factorial defense

**Status:** registered 2026-08-05 before execution  
**Attribution:** Human-directed

## Question

Holding detection timing constant, does targeted contributor isolation improve health restoration and reduce collateral intervention relative to proportional deleveraging?

## Mechanism and alternatives

Targeting should help if observable exposure, funding, and recent-loss contributions identify the modules whose reduction most efficiently restores leverage and liquidity. It should fail if EXP-030's advantage came only from earlier action, if modules are too coupled, or if proportional reduction is the more stable response.

This experiment also estimates the separate value of early warning while holding treatment fixed.
