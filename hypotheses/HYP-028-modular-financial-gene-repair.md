# HYP-028 — Modular financial gene repair

**Status:** registered 2026-08-03 before outcome parsing  
**Attribution:** Human-directed

## Question

When a five-industry portfolio is re-estimated monthly, does restricting candidate mutations to the two industries with the largest lagged distribution changes improve out-of-sample adaptation relative to equally budgeted all-gene mutation and global restart?

## Mechanism

If the portfolio problem is partially modular, unchanged industry exposures retain useful information. Fault localization should preserve those genes while repairing disrupted modules, lowering destructive search and turnover.

## Alternatives and falsifiers

- Industry returns are coupled, so the apparent modules are not causally separable.
- Mean/volatility damage scores are noisy and misassign credit.
- Unrestricted or global search benefits from interactions the local rule forbids.
- Conventional minimum variance dominates every evolutionary treatment.

Any failure of the registered joint rule rejects this implementation. A positive return alone is insufficient.

## Internal debate

- **Optimist:** the five industry sleeves are economically interpretable modules and the archive boundary is auditable.
- **Skeptic:** biological naming adds nothing unless localization beats the same search without localization.
- **Statistician:** monthly dependence and a single history limit power; use paired block bootstrap and report breadth.
- **Economist:** industry shocks spill across modules; no causal mutation claim follows.
- **Portfolio manager:** turnover and a conventional allocation baseline are mandatory.
- **ML researcher:** candidate budgets and random streams must be equal; no post-result mutation-scale tuning.

## Expected value

Novelty is moderate at best; genetic portfolio optimization is old. Practical value is unresolved. Learning value is high because the design isolates modular credit assignment from generic evolutionary search.
