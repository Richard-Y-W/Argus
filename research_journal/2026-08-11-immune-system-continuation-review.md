# 2026-08-11 — Immune-system continuation review

Richard asked Argus to run additional cycles over the immune-system research and decide whether it should continue. The first cycle reconstructed EXP-030/031 from registration through code and archived outputs. Both recorded analysis hashes still match the source, and seven focused tests pass. The evidence classification remains **NOT SUPPORTED** for targeted-treatment superiority and **SUPPORTED WITH LIMITS** for early boundary surveillance inside the synthetic benchmark.

The strongest surviving result is narrow: at fixed timing and restoration targets, targeting removed 6–7 fewer units of healthy exposure and did not detectably change terminal equity. It did not reduce invariant damage. That collateral result is partly structural because the simulator defines both the pathology and which modules count as healthy. There was no registered safety-noninferiority margin, so overlapping violation-area intervals cannot be promoted into “equally safe.”

The second cycle audited external continuation paths. FFIEC Call Reports, Federal Reserve stress-test results, and EBA stress/transparency data can supply public balance-sheet states and common stress scenarios. None directly identifies the counterfactual effect of targeted versus proportional intervention. The branch therefore remains worth continuing only through a bounded schema-and-identification audit; another synthetic controller run would consume effort without adding independent evidence.

The biological metaphor has now done its useful work: it redirected the objective from return maximization toward preserving function subject to safety. The live research problem is ordinary constrained control and prudential measurement. Future artifacts should use that language unless a biological mechanism yields a distinct, falsifiable prediction.

Research stages: adversarial synthesis, reproducibility audit, and external-data scouting. Attribution: human-directed; Richard selected the thread and requested continuation, while Argus conducted the audits.

## Researcher digest

The key design lesson is that “less intervention” is only desirable conditional on an acceptable safety loss. That is why the next hypothesis needs a safety-noninferiority margin before optimizing collateral preservation. Confidence intervals that include zero do not themselves prove equivalence.
