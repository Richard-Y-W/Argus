# Cross-domain research figures

Reproducible MATLAB-style figures connecting Argus's two active cross-disciplinary branches.

- `fig1_financial_genetics_evidence`: registered interval estimates from EXP-025 and EXP-026.
- `fig2_diversity_performance_map`: EXP-026 family-level phenotype diversity, return, and tail-risk diagnostics.
- `fig3_plex_market_integration_design`: a design schematic using verified EVE Ref snapshot facts. It is not an empirical effect figure.

Generate PNG and vector PDF versions with:

```powershell
python visualizations\2026-08-03-cross-domain-research\plot_research_program.py
```

The figures intentionally distinguish empirical results from research design and retain the synthetic/no-alpha boundary.
