# SPF composition gate — 2026-09-09

Argus revisited the leading macro candidate using the current official SPF individual workbook. The useful result is a split decision. Five quarterly core-PCE point horizons have strong within-survey completeness, but density forecasts contain only two annual horizons. The original density-term-structure idea therefore failed its three-horizon promotion rule as written.

No yield or return data were inspected, and no hypothesis was registered. The surviving question is narrower: whether a preregistered point-forecast disagreement curve changes materially across unbalanced, within-survey common-responder, and consecutive-participant estimands. Respondent IDs remain clustering and continuity aids, not verified person identities.

## Human growth digest

- **Concept:** a dataset can support several horizons while failing to support the same statistical object at those horizons.
- **Mistake to avoid:** quietly replacing density disagreement with point disagreement after learning that density coverage is insufficient.
- **Design lesson:** balanced and unbalanced panels estimate different populations; neither is automatically the correction.
- **Next question:** which population of forecasters should the primary disagreement estimand describe?
